# 50 剧本 Review 修复记录（2026-11-19）

本轮按逐剧本 Review 的确定性问题处理，不以增加断言数量代替规则修复。

## 引擎修复

- 目标 token 与供应 token 分离：`addToken(..., source)`，目标计数只统计实际放入目标的标记。修复 #24 精灵之火、#50 炸药在 5/6 人或补放三层后开局自动满足目标。
- 唯一猎杀计数：`markHunted()` 按怪物唯一 id 记录首次击倒/僵直，`goalDone('hunt')` 统计唯一怪物，不再靠反复攻击同一只僵直怪物累加。修复 #5/#15/#17/#28/#32/#38/#39/#40/#46。
- 剧本行动前置校验：`where:'rooms'`、`requireToken`、`requireTokenPrefix`、`requireAnyItem`、`requireMonsterType`、`requireFlag`，以及 `consumeToken` / `consumeTokenPrefix`。修复 #6 任意房间揭证据、#8 任意房间清洁、#28 任意房间引爆、#41 任意房间过载、#42 任意房间驱魔、#47 任意房间关传送门等。
- Setup 房间补放：固定房间缺失时先找/补普通房间；`farBasement` 找不到远端地下室时补放。修复 #10 金库、#26 祭坛、#42 储藏室、#48 血房等标记未在开局落地。
- Setup 特殊物品：找不到牌堆物品时创建同名实体物品，并支持给叛徒、揭示者或全部英雄。修复 #21 旧书、#46 解药、#48 头骨、#49 契约、#35 盐等前置。
- 新增剧本动作执行字段：`actionFlag`、`clearActionFlag`、`grantItemSelf`、`destroyAnyItem`、`takeAnyItem`。
- 剧本行动伤害类型统一：`sanity` 归一为 `mental`；构建器只接受 `physical/mental/general`。
- 通用伤害溢出改为按剩余伤害分摊，总扣除严格等于原始伤害。

- `#44/#50` 全局供应：官方是“Find 5 Fire tokens and set them aside”/“Set aside … Explosives”。新增 `setAsideToken` 与 `setup.setAsideTokens`；供应统计/扣除纳入 set-aside。`#44` 点火不再消耗火焰；`#50` 安放从 set-aside 扣除，库存为 0 时允许移动已安放的炸药。
