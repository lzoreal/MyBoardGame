## 二、第三版与当前引擎的机制差异（这是「优化」的核心）

| 维度 | 官方第三版 | 当前 `js/games/cabin.js` |
| --- | --- | --- |
| 闹鬼触发 | **某一张具体的卡**：9 张预兆（Armor/Book/Dagger/Dog/Holy Symbol/Idol/Mask/Ring/Skull）或 5 张事件（“A Splash of Crimson”/“A Vial of Dust”/“Eerie Mirror”/“Say Cheese”/“The House Is Hungry”） | `SCENARIOS.trigger = { room, omen }`（第二版的房间 + 预兆查表） |
| 叛徒判定 | 12 类：揭示者 / 隐藏叛徒 / 无叛徒 / 混战 / 揭示者左手 / 最年长 / 速度最高 / 知识最高 / 神智最低 / 预兆最多 / 力量最高 / 见事件卡 | `traitorRule` 仅 revealer / lowestSanity / highestMight / lowestSpeed / highestKnowledge / lowestMight / omenHolder |
| 预兆数量 | 9 张，**每张恰好触发 5 条剧情** | 13 张 |
| 剧本阵营 | 无叛徒（合作）/ 隐藏叛徒 / 有叛徒 / 四人混战 四种结构 | 统一「英雄 vs 叛徒」 |
| 并列处理 | 属性并列时，由**桌面上最靠近揭示者（按回合顺序）**的玩家当叛徒；若叛徒指定为「揭示者左手」，揭示者本人被排除 | 无并列规则 |
| 人数缩放 | 3/4/5/6 人 → 数值替换为 1/5/7/9 | 无 |

**建议的改造顺序（按收益从高到低）**

1. **触发模型改成「卡牌触发」**（最值钱）：把 `trigger` 扩展为 `{ card: "预兆名" | "事件卡名" | "*" }`，命中时看是哪张牌；这样 50 条剧情才能一条对一张牌，且复用官方「每张预兆 5 条」的均衡分布。
2. **`traitorRule` 扩到 12 种**，同时补上「并列取靠近揭示者」的裁决函数。
3. **加「无叛徒 / 混战」两种阵营结构**：无叛徒=所有人合作（第 4/5/7/8 号那类），混战=各自为战（9–12 号）。引擎现有 `heroGoal/traitorGoal` 二元结构装不下，需要 `camp: coop | hidden | traitor | ffa`。
4. **预兆裁剪到 9 张**，并让每张预兆对应 5 条剧本，天然对齐官方节奏。
5. 保留现有 50 条原创剧本作为「原创池」，与官方 50 条并存，用 `priority` 分层。

> 以上第 1–3 项需要改引擎，我没有动 `cabin.js`；等你确认后我再改并跑 `tools/build-cabin-packs.mjs` 与 `tests/`。

## 四、房间（已落盘 + 布局建议）

`design/cabin/rooms-3e.json` —— 46 间房 + 2 张起始平台，中英对照、已核实的楼层、已读到的效果译文。

**符号体系**（三本书一致）：螺旋 = 事件；号角 = 物品；乌鸦 = 预兆。卡面右下角图标即分类，也决定房间效果类型。

**已确认的楼层**（来自剧本册的「可研究/有火/可清扫」列表）：

| 楼层 | 房间 |
| --- | --- |
| 地面层 | 厨房、实验室、礼拜堂 |
| 地面层 / 上层 | 图书室、血屋、焦屋、坍塌房间、垃圾房 |
| 底层 | 地下墓穴、锅炉房、仪式房 |

其余 33 间的楼层官方没在可读资料里标注，只能按卡背/官方楼层分组核对，故 JSON 里留 `null`。

**数据现状**：`rooms-3e.json` 里每个房间带 `floor` / `doors` / `symbol` 三个字段，并标了来源——`official` 表示剧本册里明确写过楼层，`proposed` 是我按语义分的值，`sight` 是目测卡面读到的。**其中 `doors` 与 `symbol` 还不是官方原值**，接入前需逐张复核（44 张牌里已目测 30 张左右）。当前分布：底层 16 / 地面 15 / 上层 15。

**房间布局优化建议（可直接落到 9×7 网格）**

1. **三层配额**：底层 16、地面 15、上层 15（46 间 + 2 平台），保证每层都有「事件/物品/预兆」三种符号各至少 3 张，避免某层全是预兆导致闹鬼必然发生在地下。
2. **门的朝向要成对**：现引擎按板块四边开门，生成时要保证「新板块至少一门对齐已有门」。官方原牌的门位就是为这一点设计的，逐张抄门位比自造更稳。
3. **特殊连接房必须成对存在**：
   - 画廊 / 游戏室 → 舞厅（`Leads to Ballroom`）
   - 墓园 → 地下洞穴
   - 洗衣滑道 → 底层平台（结束回合直接坠落）
   - 坍塌房间 → 底层平台（速度判定失败坠落）
   - 神秘电梯、密梯、时光树 → 跨层跳跃
   若这些房间被放进随机牌堆，必须保证目标房间也在本局牌堆里，否则连不上。
4. **建议把 3 个「无文字房」当缓冲**：舞厅、地下墓穴、温室、爬行空间等只提供地形不给效果，用来稀释强力房间密度。
5. **本项目的 44 间 → 46 间**：官方比现引擎多 2 间，优先补「手术室 / 标本室」这类强主题房，不要补纯空白房。
